# Warning Label for Humans: One Line, Big Laugh

One-line safety warning label (127 characters) that should come printed on
every human being:

> WARNING: Do not assume silence means agreement; they may be typing a very long response, and they will send it in eleven parts.

Run `node main.ts` (Node 22). It writes the line to `output/entry.txt` and
prints it to stdout. All paths are anchored to `import.meta.url`; the program
never deletes the output directory.
